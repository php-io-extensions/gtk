# Agent guidance — php-io-extensions/gtk

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **GTK, 1:1.** One PHP function or method = one native call (GTK 4, GDK, GLib/GObject/GIO, cairo regions, graphene), under its native name and signature: `gtk_widget_set_visible(w, v)` → `GtkWidget::setVisible()`, a function on a type = method with the type prefix dropped, free GLib/GObject functions (`g_signal_connect`, `g_timeout_add`, `gtk_init`) stay functions. No defaults the native call lacks, no composites, no conveniences. The toolkit's behaviour passes through: NULL, FALSE, criticals, warnings and GError reach PHP as GTK produces them. See [`.okf/api/surface.md`](.okf/api/surface.md).
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   Here the translation is a GError the native call reported, thrown as `GError` after the call. Kept refusals and translation: [`.okf/architecture/errors-and-threads.md`](.okf/architecture/errors-and-threads.md).
4. **Glue** is the only native code beyond the calls: the trampolines GTK calls back through (signal closures, GSource callbacks, `GAsyncReadyCallback`, `GDestroyNotify`), value marshalling (PHP ↔ GValue, enums, string arrays, fds, regions), and the pointer hand-off. Each forwards the native arguments it receives and returns PHP's result to the native caller, and adds nothing else. The glue classes, as `bindings.json` `glue` names them: `GtkException`, `GError`, `GObject::pointer`, `GMainContext::pointer`. See [`.okf/architecture/callouts.md`](.okf/architecture/callouts.md).
5. **Out-parameters.** A C scalar or struct out-parameter is a by-reference PHP parameter in native position, and a gboolean result is returned (`GtkTextBuffer::getIterAtLine(?GtkTextIter &$iter, int $lineNumber): bool`, `GtkWidget::computeBounds(GtkWidget $target, ?GrapheneRect &$outBounds): bool`, `GdkEvent::getPosition(?float &$x, ?float &$y): bool`). A native NULL return is `null` (nullable stub return). Bytes cross as a `GBytes` (`GBytes::new(string|int $data, int $size)`; an int is an address, the pointer hand-off).
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the GTK headers; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. One `/* binding:<id> */` marks one line: a second line under the same check needs its own site id.
7. **A kept refusal** carries `/* binding:<id> */` on its throw line, has its `sites` entry in `bindings.json`, and a probe test in `tests/Probes` that shows the crash with the check off. Probe builds use `./configure --enable-gtk --enable-gtk-probes`; in that build env `PHPGTK_PROBE_OFF=<id>` turns one site's check off and the constant `PHPGTK_PROBES` exists. Probe tests skip on release builds. Never ship a probe build.
8. **C on the Zend API.** GObject references by hand: a boxed object holds one reference, `phpgtk_box_gobject_full` takes a (transfer full) one. Every trampoline asks `phpgtk_callout_foreign` before it calls `phpgtk_callout_invoke`, and drops a dispatch or release on a thread other than the record's owner (site `callout-owner-thread`). One `src/<Group>.c` per stub; `config.m4` lists the sources and the pkg-config modules.
9. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. Where PHP's inheritance forces a default the native call lacks (a static method beside its parent's), the stub says so in its docblock.
10. **Build.** Mac: `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`). Linux: `bash install-debian-trixie.sh`. Pest v4 at `-d memory_limit=128M`, `XDEBUG_MODE=off`, in a logged-in GUI session (`DISPLAY` / `WAYLAND_DISPLAY` on Linux). Run the test files a change touches; gate a commit on the run's exit code. Probe steps: [`.okf/runbooks/build.md`](.okf/runbooks/build.md).
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Version** is `PHP_GTK_VERSION` in `php_gtk.h`: 0.11.0. It moves only past a published tag; tags drive Packagist. `os-families`: linux, darwin.
