# What it is

A compiled PHP extension that calls **libgtk-4**. Static methods under `Gtk\GTK\`. Version **0.7.0**. PHP ≥ 8.2. GTK4 ≥ 4.10.0.

# What it is not

- Legacy PECL **php-gtk** (PHP 5)
- A tubes Canvas / UX scene / game engine
- An SDL or GLFW window factory
- A Darwin product (that is `php-io-extensions/metal`)

# Platforms

Linux (Debian, Ubuntu). One `build-linux.sh`. Do not compile on macOS.
